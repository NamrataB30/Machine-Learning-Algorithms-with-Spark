# Machine-Learning-Algorithms-with-Spark
Implementation of core Machine Learning algorithms using Apache Spark (PySpark), covering regression, classification, clustering, tree methods, Recommender System, and NLP.

Content Outline:

* Linear Regression
    * Linear Regression with E-commerse Data
    * Linear Regression with Cruise-ship Data
      
* Logistic Regression
    * Logistic Regression with Titanic Data
    * Logistic Regression with Customer-churn Data
    
* Tree Methods
    *  Random Forest Classification with Colege Data
    *  Random Forest Classification - Dog Food Data
    
* Clustering
    * Clustering with Seeds Data
    * Clustering with Hackers Data
    
* Recommender System
    * Recommender System - MovieLens Dataset
    
* Natural Language Processing
    * Tools for NLP
    * NLP Spam filter also using classifier Naive Bayes
